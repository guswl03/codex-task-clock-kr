# 코덱스 작업 시계

윈도우에서 Codex 작업의 경과시간과 예상 남은 시간을 보는 한국어 위젯입니다. 현재 사용자의 로컬 Codex 기록을 읽으며 별도 로그인이나 API 키가 필요하지 않습니다.

화면은 코덱스의 밝은 인터페이스를 참고해 흰 바탕, 옅은 회색 카드, 절제된 파란 진행 표시로 구성했습니다. 공식 코덱스 앱의 일부는 아닙니다.
창과 작업 표시줄에는 먹색 바탕에 시계와 파란 진행 표시를 그린 독자적인 아이콘을 사용합니다.

## 기능

- 진행 중인 작업의 경과시간과 최근 활동 표시
- 지난 완료 작업의 소요시간을 바탕으로 남은 시간을 `약 N분`으로 추정
- 최근 작업 선택, 긴 제목의 전체 내용 보기, 제목 숨김, 창을 항상 위에 고정
- 5초 간격 자동 갱신과 수동 새로고침
- 창이 활성화된 상태에서 `Ctrl+W`로 닫기

남은 시간은 완료 시각을 보장하지 않는 참고치입니다. 현재까지 걸린 시간보다 오래 걸렸던 완료 작업의 중앙값에서 경과시간을 빼서 표시합니다. 비교할 기록이 부족하면 예측을 생략합니다.

현재는 Codex 내부 보조 작업도 최근 목록에 포함될 수 있습니다. 제목 색인에 없는 기록은 `이름 없는 작업`으로 표시됩니다.

## 실행

Windows 10/11에서 `CodexTaskClockKR.exe`를 실행하세요. .NET Framework 4.x가 필요합니다. 자세한 사용법은 [사용법.md](사용법.md)를 참고하세요.

## 소스 빌드와 검사

`빌드.cmd`를 실행하면 Windows에 포함된 .NET Framework 컴파일러로 실행 파일을 다시 만듭니다. `app.manifest`의 시스템 배율 인식 설정과 `app.ico` 아이콘이 실행 파일에 포함됩니다. 별도의 패키지 설치는 없습니다. `Tests.cs`에는 기록 해석, 시간 추정, 화면 배치 검사가 들어 있습니다. 아이콘은 PowerShell에서 `./아이콘-만들기.ps1 -OutputDirectory .`을 실행해 다시 만들 수 있습니다.

## 개인 정보

프로그램은 현재 사용자의 `session_index.jsonl`과 `sessions` 폴더를 읽습니다. `auth.json`을 열지 않고, 네트워크 통신이나 원격 전송 기능이 없습니다. Codex의 로컬 기록 형식이 바뀌면 표시가 달라질 수 있습니다.

이 프로젝트는 [Codex Pulse](https://github.com/wudongshu2002/codex-pulse)의 아이디어를 참고한 독립 구현입니다.
